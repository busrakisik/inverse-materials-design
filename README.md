# Bayesian Hypothesis Search (BHS) for Autonomous Materials Discovery

**BHS (Bayesian Hypothesis Search)** is a mathematically formal framework for autonomous scientific discovery in computational materials science. By coupling **Sequential Bayesian Evidence Accumulation** with **Adaptive Monte Carlo Tree Search (PUCT)** and **Machine Learning Force Fields (MLFF)**, BHS systematically explores crystal structure candidate spaces with quantified uncertainties and rigorous data provenance tracking.

---

## 🏛️ Core Architectural Principles

1. **Sequential Bayesian Evidence Accumulation**:
   Posterior probabilities over crystal structure hypotheses ($H_i$) are updated sequentially under Naive Bayes conditional independence assumptions:
   $$\mathcal{P}(H_i \mid \mathcal{E}_{1:k}) \propto \mathcal{P}(H_i) \prod_{j=1}^k \mathcal{L}(\mathcal{E}_j \mid H_i)$$

2. **Strict Data Provenance**:
   Every metric, energy value, and probability generated by the system is explicitly tagged with its origin (`MEASURED`, `DERIVED`, `RETRIEVED`, or `ILLUSTRATIVE`) to guarantee scientific reproducibility.

3. **Decoupled Engine & Reproducibility Bundles**:
   The algorithmic core operates independently as the standalone `bhs` Python package, producing self-contained "Provenance Bundles" containing configuration snapshots, execution logs, and output manifests for every run.

## 🚀 Quickstart

### Installation

```bash
git clone [https://github.com/busrakisik/inverse-materials-design.git](https://github.com/busrakisik/inverse-materials-design.git)
cd inverse-materials-design
pip install -e .

Run Single Reconstruction Experiment (CLI)
To launch a fully reproducible single-run experiment (e.g., LiFePO₄ reconstruction):
python -m bhs.cli --config configs/reconstruction_lifepo4.yaml --out-dir runs/run_001
