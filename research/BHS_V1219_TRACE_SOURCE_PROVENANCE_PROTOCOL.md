## Research question and what is actually published

Does the **original 2020 crossed-barrel experiment** have independently available and authentically mappable individual force–displacement traces for each of the 600 distinct designs × 3 physical replicates in the *existing* V11 development study?

- Original article: A. E. Gongora and colleagues, *Science Advances* **6** (2020), eaaz1708, DOI `10.1126/sciadv.aaz1708`, open article `https://pmc.ncbi.nlm.nih.gov/articles/PMC7148087/`. It reports force–displacement traces recorded for each experiment in a local database and demonstrates visually distinct behaviors labeled "too strong", "brittle" and "ductile". This is **evidence that experimental traces were produced**, not evidence that raw per-replicate files with design IDs are independently downloadable or that mechanism labels were separately verified. Figure illustrations must NEVER be copied into fabricated individual curves or labels.
- Original author's source catalog `https://www.kablab.org/data`, which includes an original **Crossed Barrel Dataset** public Dropbox folder link and a **different 2021 simulation-expanded Crossed Barrel Dataset** folder link. Web access reaches the official folder entrypoints but did **not** reveal individual file names, raw curve bytes, cryptographic hashes or exact V11 replicate-to-curve links. **Status `LINK_VERIFIED_CONTENT_NOT_ENUMERATED`**, not SOURCE_FILE_VERIFIED.
- Institutional source listing for **this 2020 original**: `https://open.bu.edu/items/e64c20e4-0f56-4a90-ac14-db26698d5faf`, handle `2144/49164`. ## Owner's three-part feature rule is mandatory

Every candidate input must show separately: **(1) exact source and field creation lineage, (2) derivation before the expensive experiment under evaluation, (3) accessibility by BHS and all baselines when selecting that experiment**. Raw force curves are **POST-experiment observations**, never available as a candidate's pre-query input. After querying a candidate, a *legitimately acquired* recorded curve may become that candidate's revealed observation. Any full dataset of curves is private to a separate evaluation owner; it must NOT be passed directly to the selection policy.

Source metadata and scientist-verified experimental IDs are required to bind each trace to precisely one original physical replicate. A tuple of four identical design coordinates does **not** uniquely identify three distinct physical replicates and cannot recover order/timestamps. Grouping-only source keys are insufficient as a per-run provenance certificate. Do not use inferential fuzzy joins, sorted-order guesses, image-derived labels or measurements reconstructed from reported toughness to assign IDs.

## Frozen 2020 technical ingestion gate, before any file is available

A future test of **original 2020** archived responses must require all of:

1. Independent archival source identifier, exact immutable download endpoint, creator, source-licensed terms and content integrity verification by a **separately obtained trustworthy archive digest** (not a SHA-256 copied from a locally re-created ZIP). If no such reference exists, verification status stays `UNVERIFIED`, even if arbitrary bytes can be hashed.
2. Actual manifest of source-declared **1,800 distinct physical replicate IDs**, exactly **600 independently distinct design groups × 3** (applicable to the historical V11 grid study only), with four design parameters `n,theta,r,t`, a group key and a **nonambiguous sample ID** recorded in the original metadata. If a source has a different scope, do not force it into this grid. The parser must reject duplicate IDs, duplicate archive members, missing IDs and any one-to-many or many-to-one invented record assignment.
3. Each trace's original filename must be independently and exactly linked to its actual sample ID (from archived machine log or author metadata), with a recorded real assay/instrument time, units, curve type, and acquisition chronology. Filename patterns, tuple order and the matching *count* alone do not establish authenticity. A curve missing due to unsuccessful testing is **missing**, never filled with a surrogate or an FEA simulation.
4. Any future curve parser must retain raw files unchanged, validate unit conversions and machine stopping/truncation rules in a separately frozen protocol and never grant label visibility before the selected assay. V12.19 does **not** parse actual force/displacement values, infer a physical failure class, calibrate a likelihood or score a scientific policy.
5. Independent reviewer/institutional confirmation of source rights, independently mapped replicate identities, actual time/order and whether curve-level mechanics can distinguish competing hypotheses. A self-completed schema or green software test cannot stand in for human source authentication.
