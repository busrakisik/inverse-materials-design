## Distinct findings from original author and institutional sources

1. **Actual original crossed-barrel paper:** Gongora et al., *Science Advances* **6** (2020), eaaz1708, DOI `10.1126/sciadv.aaz1708`, source `https://pmc.ncbi.nlm.nih.gov/articles/PMC7148087/`. The original authors report 600 unique parametric designs, each physically tested in triplicate, and stored each experiment's weight, **force–displacement curve**, and toughness in their local database. Figures compare "too strong", "brittle" and "ductile" response categories, but figures do **not** provide independently usable labels/traces for all V11 replicates. Physical curves were **measured**; this does not establish that full raw files are openly downloadable or mappable.
2. **Original author data portal:** `https://www.kablab.org/data` links a source folder for **Crossed Barrel Dataset (2020)**; source link resolves to `https://www.dropbox.com/scl/fo/94xtwr8lx6eaj2vymbpzw/AChuSgwzm6Vay8cMeDEwJVQ?rlkey=9c9n507l4jyg1lfe5o7yh3vwn&dl=0`. It also links a distinct **2021 simulation-expanded Crossed Barrel** folder. Neither public page yielded an individual 2020 file listing, verified file bytes, source checksums, run timestamps or the one-to-one original V11 replicate join in the available research interface. **A public folder URL is not data availability proof.**
3. **2020 institutional bibliographic entry:** Boston University record `https://open.bu.edu/items/e64c20e4-0f56-4a90-ac14-db26698d5faf`, handle `2144/49164`, lists original authors; live fetch did not expose an original individual raw-curve inventory. Do not claim that repository contains sample-level curves solely from the title.
4. **Different 2021 source:** `https://pmc.ncbi.nlm.nih.gov/articles/PMC8010472/` and author's separate folder report FEA-augmented crossed-barrel research. Finite-element outputs are modeled, **not automatically physical 2020 experiments**, and cannot be used as independent physical replicate curves without source-mapped IDs.
5. **Different 2022 lattice experiment:** `https://open.bu.edu/items/ff8a7bce-2907-4efa-aeed-943287988e8c`; publicly indexed `RawTestData_Quasistatic.zip` 133.84 MB and `RawTestData_Impact.zip` 120.54 MB, and author page advertising 821 quasistatic and 247 impact tests. ## Scientific consequence and existing unfavorable empirical evidence

The 2020 paper's demonstration of brittle and ductile shapes does NOT give an independently joined trial-level physical mechanism readout for the V11 600 × 3 pool. An inferred response category from toughness alone would be a post hoc and potentially leaky pseudo-label; forbidden. Source experimental failure categories need actual archived machine curves or qualified source-reported labels, independently matched to actual run IDs, and a prospectively frozen physical classification method before use.

V12.18's two existing statistical model forms, additive geometry vs added twist×thickness interaction, do not identify distinct physical failure mechanisms. Their manufactured four-candidate information gain was extremely small (`2.947743603209929e-6 nats`) and must not be optimized away. Real data did not provide a new Bayesian likelihood calibration or complete BHS comparison here.

The only existing honest original measured-data matched-budget study is V11 **component only**, on five **development** seeds: 600 designs × three physical toughness replicates, 16 designs/48 acquired responses per method per seed. Mean historical simple regret in joules, lower better: **GP–ARD EI 7.363, RF–UCB 8.983, BHS v5 statistical kernel portfolio EI 9.368, random 15.951**. BHS's v5 kernel component loses to serious reference methods. This source finding is unchanged; full hypothesis-aware BHS performance remains **NOT EVALUATED**.
